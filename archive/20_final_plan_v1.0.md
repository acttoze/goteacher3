# 티로드(T-Road) 최종 기획서 v1.0 — 2026-10-25

> 의장: Claude · 참석: 일반 교사(초4 담임 9년차), 생산성 전문가, 학교업무 전문 교사(교무부장 4년), UI/UX 전문가
> 근거: 고티처 운영 DB 실측(research/01), 마케팅·사이트·경쟁(research/02), 코드 인벤토리(research/03), 1·2라운드 회의록(r1_*, r2_*)

## 0. 한 줄
**"쪽지는 그대로, 원본은 한 곳에."** 메신저로 흩어지는 학교 일을 '오늘' 한 장과 '끝나는 요청'으로 바꾸는 학교 업무 원장.

## 1. 왜 고티처는 멈췄나 (실측)
| 증상 | 수치 | 원인 |
|---|---|---|
| 확산 실패 | 가입 학교 117곳 중 49곳 회원 1명, 2025년 이후 신규 정착 0곳, 신규 학교 동료 합류 0곳 | 4자리 PIN을 말로 전달해야 학교에 들어옴. 받는 사람이 가치를 먼저 못 봄 |
| 이탈 | 2023 가입자 1,819 → 현재 활성 73(4%) / 일정 작성자 1,277 → 468 | 등록하는 사람만 이득인 '일기장' 구조 |
| 안 봄 | 일정당 조회 1.73회, 댓글 0.6%, 첨부 1.2% | 변경 표시·확인 행동이 없음, 소통은 메신저로 |
| 취합 실패 | 고시트 18건(대부분 테스트) | 웹 시트 = 구글 시트 열화판. hwp 현실과 합본이 없음 |
| 입력 고통 | 제목 38%에 시간, 14%에 `이름|출장(…)` 수기 | 교시·장소·대상·복무 필드 없음, 시간 단위 일정 없음 |
| 운영 수작업 | Q&A: 관리자 변경·가입 승인·메뉴 안보임·인쇄 깨짐 | 그누보드 권한 체계, 인쇄 레이아웃 없음 |

## 2. 타깃과 진입 순서
1. **보내는 사람(챔피언)**: 취합·주간계획을 뿌리는 교무계원·학년대표·부장 → 첫 사용자
2. **받는 사람**: 담임·전담 → 로그인 없이 링크로 참여, '오늘'을 보며 흡수
3. **결정권자**: 교감·교장 → 복무·보강판, 확인율, 처리 추적으로 학교 결제
- 초등 먼저(학년당 4~6반 구조가 취합 루프와 맞음) → 중·고는 시험감독표·보결표로 v2 진입
- 온보딩 적기: **2월 셋째 주(새 학년 세팅)**, 2차 3월 첫 주(취합 폭발기)

## 3. 핵심 기능 (MVP)
### ① 모으기(취합) — 바이럴 엔진
- hwp·엑셀 표를 **붙여넣으면** 머리글이 입력 필드로, 행(학년·반·이름)이 제출 단위로 바뀜
- 대상 선택(학년·부서·업무분장) → **반별 "내 칸만" 링크** + 메신저용 문구 자동 생성
- 받는 사람: 비로그인 모바일, 처음 한 번 "누구신가요?" 이름 선택 → 기기 기억, 30초 제출, 마감 전 수정
- 보내는 사람: **실시간 합본** · 미제출 칩(누르면 독촉 문구 복사) · D-1/당일 8시 자동 리마인드 · 마감 잠금(지각 표시) · **원본 양식 그대로 xlsx/hwpx 내보내기**(꼬리말 "티로드로 취합")
- 제출 = 확인 (이중 확인 금지)

### ② 오늘 — 매일 여는 이유
- 상단: **오늘 바뀐 것**(분필 노랑 점) — 어제 이후 변경된 일과·공지·시간표만
- 좌: 내 시간표 + **보강 들어갈 교시 맨 위**
- 중: 학교 일과를 **교시 축** 타임라인으로(시계 X) + **복무 레인**(출장·조퇴·외출·연가, "보강 필요 3교시" 빨간 칸)
- 우: 나에게 온 것 — 마감·미제출·확인 요청, 1클릭 처리
- NEIS 학사일정·급식 자동(입력 0)

### ③ 한 줄 입력 — 입력 5초
- "내일 3~4교시 4학년 과학실 안전교육 @김민준" → 날짜·교시·대상·장소·참석자·유형 **칩**으로 실시간 분해, 칩 클릭 수정, Enter 저장
- 학교 사전(특별실·학년반·교직원·복무유형) 기반 규칙 파서(MVP) → 쪽지 전문 AI 변환은 v1.5
- 장소 중복 시 즉시 경고(특별실 충돌)

### ④ 공지 — 바뀐 걸 모르는 일이 없게
- 수정마다 v2, v3 + **변경점 diff**(~~강당~~ → 체육관)
- '실질 변경'(일시·장소·대상·제출물) 토글 시에만 이전 열람자에게 diff 카드 재노출(오늘 바뀐 것 안에서)
- 확인 모델: 기본 **열람=확인**(2초 이상 or 끝까지 스크롤, 링크 미리보기 봇 제외). **'확인 필수'는 부장·교감 권한 + 공지에만**, 미확인자 명단·1클릭 리마인드

### ⑤ 일정 주간·월간 + 인쇄
- 주간(교시 축)/월간(월중행사표). **인쇄 전용 레이아웃**: 월중 A4/A3 가로, 주간 A4 세로, 흑백 기호(◆행사 ■업무 ○복무), 공휴일 음영, 넘침 "+N 별지", 머리말 학교명·결재란·출력일

### ⑥ 교감 현황판
오늘 복무·보강판(미배정 빨강) · 마감 임박 취합(제출률·1클릭 리마인드) · 확인 필수 공지 확인율 · 이번 주 특별실·행사 충돌

### ⑦ 시작하기
- 첫 취합 링크로 들어온 교사 = 자동 합류(가입 폼 없음). 학교 초대 링크 + QR(교무실 게시용)
- 업무분장 표 붙여넣기 → 구성원·부서 일괄 생성(이름만, 승인 대기 없음). 도메인 메일 인증은 선택
- 시정표 붙여넣기 → 교시 축·묶음 알림 시각 자동

## 4. 알림 정책
- **수업 중 푸시 금지.** 기본 묶음 알림 3회: 08:20 · 점심 · 방과후 (시정표 기반, "다음 알림 12:20" 표시)
- 예외 즉시: ①당일 내 보강 배정 ②관리자 '긴급' 당일 일과 변경(하루 1회 제한)
- 메신저 연동: 카드마다 짧은 링크 + 복사용 문구 (쿨메신저 쪽지에 붙임)

## 5. 하지 않는 것 (회의 합의)
칸반·태그·하위작업 · 채팅·댓글 스레드 · 결재·공문 원문 연동(에듀파인 영역) · 나이스 상신 체크·공문 메타 수기입력(이중업무) · 개인 GTD 설정 · 학생 개인정보 저장 · 단축키 중심 UX(제공은 하되 노출 X)

## 6. 데이터·보안 원칙
- 교직원 업무 데이터만. 학생 이름·연락처 비저장(취합 양식에 학생 개인정보 열 감지 시 경고)
- 공문은 원문 X, 필요시 제목·기한만
- 데이터 모델: 학교 · 구성원(교사 단위 시간표 포함) · 부서/업무분장(연도별) · 장소 · 일정(교시 범위·대상·장소·참석자·유형) · 복무 · 요청/제출(셀 단위) · 공지(버전) · 열람/확인 로그
- 학교 단위 격리, 링크 토큰 + 학교 명부 선택, CSAP·교육청 화이트리스트 체크리스트 제공
- 고티처 교훈: 권한 검사 누락·PIN 평문·SQL 문자열 결합 금지

## 7. 비즈니스
- 개인·학년 무료(취합·오늘·공지 전부). **학교 플랜**: 교감 현황판, 확인 필수, 자동 리마인드 무제한, 연도 인수인계 보관, 학교 도메인/SSO, 계산서 → 연 29~49만원(학급 수)
- 고티처의 "유료·무료 기능 차이 없음" 문제를 '관리자 가치'로 분리
- 획득: 산출물 검색어(업무분장 3,090/월, 월중행사표 320/월) 랜딩 = 바로 쓰는 템플릿 + 합본 꼬리말 바이럴 + 인디스쿨 시즌(1~2월)
- 고티처 사용 학교 이전: 고티처 일정 CSV 가져오기
