## 0. 한 줄
**"쪽지는 그대로, 원본은 한 곳에."** 메신저로 흩어지는 학교 일을 '오늘' 한 장과 '끝나는 요청'으로 바꾸는 학교 업무 원장.

## 2. 타깃과 진입 순서
1. **보내는 사람(챔피언)**: 취합·주간계획을 뿌리는 교무계원·학년대표·부장 → 첫 사용자
2. **받는 사람**: 담임·전담 → 쪽지 링크를 PC 브라우저에서 열어 로그인 없이 참여, '오늘'을 보며 흡수
3. **결제 주체**: 학교(교감·행정실) → "관리자 특혜"가 아니라 **학교 전체 업무비**로 결제. 교감은 감시자가 아니며, 역할은 복무·인사 담당 쪽으로 옮겨 가는 추세
- **사용 환경 = PC 전용.** 학교 업무는 PC에서만 하고 교사는 늘 PC 앞에 있다. 모바일 화면은 만들지 않는다
- 초등 먼저(학년당 4~6반 구조가 취합 루프와 맞음) → 중·고는 시험감독표·보결표로 v2 진입
- 온보딩 적기: **2월 셋째 주(새 학년 세팅)**, 2차 3월 첫 주(취합 폭발기)

## 3. 핵심 기능 (MVP)
### ① 모으기(취합) — 바이럴 엔진
- hwp·엑셀 표를 **붙여넣으면** 머리글이 입력 필드로, 행(학년·반·이름)이 제출 단위로 바뀜
- 대상 선택(학년·부서·업무분장) → **반별 "내 칸만" 링크** + 메신저용 문구 자동 생성
- 받는 사람: 쿨메신저 쪽지 링크 → **PC 브라우저**, 처음 한 번 "누구신가요?"(그룹별 명부) + **휴대폰 문자 인증 1회** → 그 PC를 1년 기억, 그 뒤로는 로그인 화면 없이 30초 제출, 마감 전 수정
- **받는 방식**: 기본은 티로드 안(학교 구성원). **외부 링크**는 옵션 — 명부 밖(방과후 강사·첫날 기간제·업체)용, 칸 하나 제출만, 마감 후 만료
- **양식 가져오기 순서**: ① **직접 입력(기본)** — 시트 모양 표에 받을 항목 이름만 적음(A·B열 학년반·담임은 대상에서 자동, 형식 글자·숫자·선택지·날짜·링크) ② **자주 쓰는 양식** — 누르면 바로 만들어짐: **학습준비물 신청**(반별 여러 줄, 금액=수량×단가, 학급 예산 잔액·학년 합계 자동), **교직원 연수 이수 현황**(법정의무연수 14개 × 전 교직원, 이수번호, 연수별 이수율) ③ 표 붙여넣기 ④ hwpx 올리기(v1)
- 모으기 형태 3가지: **한 줄형**(반·사람마다 1줄) · **여러 줄형**(한 반이 여러 줄, 예: 물품) · **행렬형**(사람 × 항목, 예: 연수)
- **hwp 처리 단계** — 의도는 "hwp에서 취합 표 부분만 꺼내 칸 단위 DB로 만들고 → 칸별로 걷고 → 다 모이면 다시 hwp로 내보내기"
  - MVP: 한글에서 표를 **복사해 붙여넣기**(파일을 열지 않음) → 출력은 xlsx + **합본 표 복사 → 한글에 붙여넣기**
  - v1: **hwpx 파일 업로드** → 파일 안 표 목록에서 취합 표 선택 → 다 모이면 **같은 파일의 그 표 칸만 채워** hwpx로 돌려줌(본문·결재란 유지). hwpx는 압축 XML(OWPML 표준)이라 읽기·쓰기 가능
  - 보류: 구형 바이너리 **.hwp**는 "한글에서 hwpx로 저장" 안내(서버 변환은 추후 검토)
- 보내는 사람: **실시간 합본** · 미제출 칩(누르면 독촉 문구 복사) · D-1/당일 8시 자동 리마인드 · 마감 잠금(지각 표시) · xlsx 내보내기·합본 표 복사(MVP), 원본 hwpx 채워 받기(v1) (꼬리말 "티로드로 취합")
- 대상 지정: **그룹(학년·교무실·행정실…)·직책·부서**로 고름 → 받는 사람 '오늘'의 '나에게 온 것'에 정확히 꽂힘
- 제출 = 확인 (이중 확인 금지)

### ② 오늘 — 매일 여는 이유
- 상단: **오늘 바뀐 것**(↻ 아이콘) — 어제 이후 변경된 일과·공지·시간표만
- 좌: 내 시간표
- 중: 맨 위 **전일**(시간 미정·종일) + 그 아래 **교시 축**(왼쪽에 1블록·2블록·3블록·방과후 표시), 카드마다 작성자(그룹) + 복무(출장·조퇴·외출·연가, 공유만)
- **입력 정밀도 원칙: 날짜는 필수, 시간은 선택.** 날짜만 넣은 일정은 전일에 모이고, 시간이 필요한 사람이 **카드를 교시 줄로 끌어** 정한다. 카드 **위·아래 끝을 끌면** 교시 단위로 길이 조절, 빈 교시 줄 더블클릭 = 그 교시에 카드 생성, 교시 카드를 전일로 끌어 올리면 시간 미정. 끌 수 있는 사람 = 쓴 사람 + 같은 그룹. 드래그 대신 카드 클릭 → 시작·끝 교시 선택도 가능
- 이미 정해진 시간을 바꾸면 관련 선생님 '오늘 바뀐 것'에 알림(처음 시간을 정하는 건 알리지 않음)
- 입력을 덜어 주는 경로: NEIS 자동 · **주간교육계획 표 붙여넣기**(교무부장이 이미 만드는 표 → 한 주 일정 일괄 등록, 시간 칸이 비면 전일) · 한 줄 입력 · 모으기 마감 자동
- 우: **[나에게 온 것 | 학교 전체]** 토글 — 기본은 나를 대상으로 한 마감·미제출·확인 필수(그룹·직책·부서로 판정), '학교 전체'는 진행 중인 취합·확인 필수 공지 전부(마감순, 리마인드용). 구 교감 현황판의 '마감 임박·확인 필수'가 여기로 옴
- NEIS 학사일정·급식 자동(입력 0)

### ③ 한 줄 입력 — 입력 5초
- "내일 3~4교시 4학년 과학실 안전교육 @김민준" → 날짜·교시·대상·장소·참석자·유형 **칩**으로 실시간 분해, 칩 클릭 수정, Enter 저장. **교시를 안 쓰면 전일**(v1.1의 '방과후' 자동 배정 폐지)
- **제목은 쓴 문장 그대로** 저장(날짜 표현·@참석자만 뺌). 교사 과반이 내용을 제목에 길게 넣어 달력에서 바로 읽는 걸 선호(고티처 설문). 칩은 검색·충돌 경고·필터용 메타데이터
- 학교 사전(특별실·학년반·교직원·복무유형) 기반 규칙 파서(MVP) → 쪽지 전문 AI 변환은 v1.5
- 장소 중복 시 즉시 경고(특별실 충돌)

### ④ 게시판 — 공지 · 수리요청 · 양식 자료실 (v1.2: 메뉴 '공지' → '게시판')
**공지** — 바뀐 걸 모르는 일이 없게
- 수정마다 v2, v3 + **변경점 diff**(~~강당~~ → 체육관)
- '실질 변경'(일시·장소·대상·제출물) 토글 시에만 이전 열람자에게 diff 카드 재노출(오늘 바뀐 것 안에서)
- 확인 모델: 기본 **열람=확인**(2초 이상 or 끝까지 스크롤, 링크 미리보기 봇 제외). **'확인 필수'는 부장·교감 권한 + 공지에만**, 미확인자 명단·1클릭 리마인드

**수리요청** — 필터 **시설 / 정보**
- 요청: 분류 · 위치(기본 우리 반) · 한 줄 내용 · 메모 · 사진 · 급함. 상태 접수 → 방문 예정 → 처리 중 → 완료, 바뀔 때마다 요청자 🔔
- 시설 = 행정실 시설 담당(교직원 계정)
- 정보 = 외부 유지보수 업체 → **업체 계정**: 정보부장이 담당자 **휴대폰 번호로 초대**(문자 인증, 비밀번호 없음), 볼 수 있는 건 **정보 수리요청 게시판 하나**, 요청자 이름 대신 **위치만**, **계약 기간 자동 만료**, 담당자 교체 = 번호만 교체(이전 사람 즉시 차단), 접속 기록. 업체 한 계정으로 담당 학교 여러 곳을 한 화면에서(학교 간 확산 경로)

**양식 자료실** — 고티처 양식 자료실과 동일
- 분류 학교·교육청, 79건(설명 · 이렇게 쓰세요 · hwpx 첨부 1개), 목록(분류·제목·작성자·조회·날짜), 최신·조회·다운로드 정렬, 20건 페이지, 검색
- 운영자만 등록, 보기·다운로드는 로그인 없이 누구나(검색 유입). 더한 것: '이 양식의 표로 모으기'

### ⑤ 일정 주간·월간 + 인쇄
- 주간 = **전일 + 4블록**(1블록 아침·1·2교시 / 2블록 중간놀이·3·4교시 / 3블록 점심·5·6교시 / 방과후), 월간 = 월중행사표. 블록은 블록수업에서 실제로 쓰는 이름(새 이름을 만들지 않음, 블록제가 아닌 학교는 '1·2교시…'로 바꿈 — 확인 필요). 교시까지 정한 일정은 블록 안에 교시를 함께 표시
- **카드 색 원칙**: 흰 카드 + 얇은 테두리, 유형(행사·업무·회의)은 **제목 앞 작은 색 점**, 면 색은 **나와 관련된 카드에만**(내가 쓴 것·대상이 우리 반·우리 학년·전 교직원), 최근 변경은 **↻ 아이콘 + 노란 테두리**. 왼쪽 색띠·유형 기호는 화면에서 뺌. 카드에 **제목 + 작성자(그룹)** — 주간은 제목 아래 `송민재 · 4학년`, 월간은 `[4학년] 제목`
- 긴 제목은 **자르지 않고 줄바꿈**. 상세 내용 칸은 선택(접힘)
- **인쇄 전용 레이아웃**: 월중 A4/A3 가로 선택, 주간 A4, 흑백 기호(◆행사 ■업무 ▲회의 ○복무, 인쇄에서만), 공휴일 음영, 넘침 "+N 별지", 머리말 학교명·결재란·출력일

### ⑥ 학교 (전체 교사 공용) — v1.0 '교감 현황판' 대체
- **모든 선생님이 같은 화면.** 교감 전용·유료 전용 화면 없음(관리자 특혜 거부감, 교감 ≠ 감시자)
- 상단: **오늘 복무 현황**(출장·조퇴·외출·연가, 이름·그룹·시간). 결재는 나이스, 티로드는 공유만
- 탭 1 **학년분장 · 그룹 현황**: 그룹별 구성원과 직책을 한눈에. 본인이 직접 고치고 즉시 전원에게 반영(승인 없음, 이력 보관)
- 탭 2 **업무분장 · 부서**: 학년분장과 **같은 카드 UI** — 부서마다 카드, 줄마다 업무 · 담당 · 그룹. 연도별 보관 → 다음 해 2월 그대로 불러오기
- **보강 배정은 하지 않는다.** 담당자가 이미 다른 곳에서 처리하는 일을 티로드에 다시 입력하면 이중업무

### ⑥-1 그룹 (고티처의 연락처+소속+그룹을 하나로)
- **그룹 = 근무 위치(소속)**, **부서 = 업무분장 축** — 둘은 별개(한 교사가 '4학년' 그룹이면서 '방과후돌봄부')
- 모든 학교 공통 기본 그룹, 가입 시 선택: **1~6학년 · 교무실 · 행정실 · 급식소 · 기타/지원**
- 직책(고정 목록 + 직접 입력):
  - 학년: 1반~N반, 전담 — **전담은 주 학년 그룹에 '전담'으로 소속**(메모에 과목)
  - 교무실: 교감, 교무부장, 교무, 교무실무사, 행정원 (+ 아래 공용 직책)
  - 행정실: 실장, 차장, 계장, 주무관
  - 급식소: 영양교사, 조리사, 조리실무사
  - 기타/지원: 공용 직책
  - **공용 직책 — 교장·보건·사서·전문상담·특수·돌봄전담사는 교무실과 기타/지원 양쪽에서 선택 가능**(학교 사정에 맞게)
- 새 학년(2월)마다 "그룹 다시 고르기" 안내

### ⑦ 시작하기
- 첫 취합 링크로 들어온 교사 = 자동 합류(가입 폼 없음). 이름 → **그룹 → 직책**만 고름. 학교 초대 링크 + QR(교무실 게시용)
- 기본 그룹은 미리 준비됨 → 업무분장 표 붙여넣기(선택)로 부서·업무 생성(승인 대기 없음). 도메인 메일 인증은 선택
- 시정표 붙여넣기 → 교시 축·묶음 알림 시각 자동

## 4. 알림 정책 (PC 전제)
- 채널: **앱 우상단 🔔 알림** + **브라우저 웹 알림**(크롬·엣지·웨일이 켜져 있으면 윈도우 알림센터 토스트). **전용 PC(윈도우) 에이전트**는 차후 개발 — 노션 PC 앱 같은 알림 체계
- **수업 중 PC 알림 창 금지.** 교사 PC 화면은 수업 중 교실 TV·전자칠판에 송출되는 경우가 많아 학생에게 노출됨 → 수업 중에는 🔔에만 쌓음
- 기본 묶음 알림 3회: 08:20 · 점심 · 방과후 (시정표 기반, "다음 알림 12:20" 표시)
- 예외 즉시: 관리자 '긴급' 당일 일과 변경(하루 1회 제한) — 보강 배정 알림은 삭제(보강 기능 제외)
- PC 에이전트 개발 시 확인: 학교 PC 설치 권한, 보안 프로그램 충돌, 교육청 화이트리스트
- 메신저 연동: 카드마다 짧은 링크 + 복사용 문구 (쿨메신저 쪽지에 붙임)

- 교직원 업무 데이터만. 학생 이름·연락처 비저장(취합 양식에 학생 개인정보 열 감지 시 경고)
