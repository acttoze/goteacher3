## 리드 결정 (사용자 요청을 해석한 것. 틀리면 사용자가 고침)

| 쟁점 | 결정 | 이유 |
|---|---|---|
| 수리 요청 위치 | **나눈다.** 교내 게시판 수리 요청 = 시설만. 정보 = 교외 '정보수리방'. 3라운드의 "수리 교내 통합"을 뒤집음 | 사용자 "교내·교외의 확실한 분리", `23_inside_outside.md` 원안 |
| 업체 계정 카드 위치 | 정보수리방의 오른쪽 칸(지금과 같은 자리) | 사용자 "현재 위치는 좋고" |
| 정보수리방 접근 | 학교 공간 회원(로그인) + 비밀 링크 업체. 동학년 공간엔 메뉴 없음 | 사용자 "정보수리는 로그인 전용", 수리는 학교 플랜 기능 |
| 업체 사용 기간 끝 | **칸과 컬럼을 없앤다.** 끊는 수단은 접근 끊기·재발급·학교 플랜 만료 | 사용자 요청. 28·32번의 "만료일 유지" 결정을 대체 |
| 업체 링크 항상 복사 | 원문 저장 안 함. `token = HMAC(SECRET_KEY, "vendor-link:" + nonce)`로 다시 만든다(`nonce`만 DB). 이미 발급한 계정(nonce 없음)은 "새 링크 발급" 안내. 복사 단추는 관리자·수리 담당자에게만 | DB만 새어서는 링크를 못 만들게 유지 |
| 일정 보기 | **일간·주간·월간** 셋. 마지막 모드는 쿠키(`gt_sched_mode`, 1년, HttpOnly)로 기억 | 주간은 이미 있음. 서버가 바로 그 모드로 그린다 |
| 일정 위 한 줄 입력 | 일정 화면에서 **뺀다**(오늘 화면의 한 줄 입력은 유지) | 사용자 "별도 버튼이 아니라" |
| 칸 입력 해석 | 날짜·블록은 **칸이 이긴다**. 장소·대상은 한 줄 파서로 뽑고 제목은 파서 결과 | 쓰던 겹침 알림 유지 |
| 글쓰기 모달 | 공지 쓰기·수리 요청(시설·정보) 모두 모달. **고치기는 지금 화면 유지** | 사용자는 '글쓰기'만 말함 |
| 바로보기 전체 화면 | 급식 화면 안 iframe을 그 클릭에서 `requestFullscreen`. 전체 화면이 끝나면 iframe 제거. 못 쓰면 새 탭 | 브라우저 제약: 새 창에선 클릭 없이 전체 화면을 못 띄움 |
| 추천 자격 | 후기 자격과 다르게 **구글 회원이면 됨**(손님 불가). 업체 추천 `_can_suggest`와 같다 | 사용자 "고티처 회원만" |
| 협력업체 추천 | 있는 '업체 추천하기'·배지 후기를 추천 기능으로 본다(새 기능 없음, 안내만) | 이미 구현됨 |
| 양식 추천 | 양식마다 회원 1표(누르면 켜고 끔), 수 표시, 정렬에 '추천 많은 순' | 사용자 "추천 기능" |
| 커뮤니티 범위 | **전국 하나**(공간에 속하지 않음). 구글 회원만 보기·쓰기, 손님·비로그인은 안내 + 로그인. 검색 제외 | 사용자 "로그인 전용", 교외 |
| 닉네임 | 처음 들어올 때 입력(2~12자, 전체에서 중복 불가, 하루 1번 바꾸기). 화면 어디에도 이름·학교·메일 없음(`author`는 서버 안에만) | 사용자 "편한 공간" |
| 커뮤니티 안전장치 | 글·댓글·본인 지우기·신고. 운영자 관리 명령으로 내리기, 빈도 제한, 학생 개인정보 안내, 약관·처리방침 조항, 계정 삭제 시 글은 "나간 선생님"으로 | 익명 공간은 운영 수단이 먼저 있어야 함 |

| Q2 | 일정 칸 안 추가: 날짜 칸 빈 곳을 누르면 그 자리에 빈 카드(입력칸)가 생기고 Enter·칸 밖 누르기로 저장, Esc·빈 내용은 취소. 모든 칸 아래에 카드 한 칸 높이 빈 줄 항상. 학교 공간은 카드 안에 '볼 사람'. 빈 줄은 키보드로도 닿는 단추. 위 한 줄 입력 제거 | 일정이 꽉 찬 칸에도 추가 가능. 카드를 눌렀을 때는 추가가 안 열림. 저장 뒤 그 칸에 뜨고 스크롤 유지 |

| Q4 | 공지 쓰기·수리 요청을 목록 화면 위 모달로. 첨부·검사 오류는 모달이 열린 채 입력값 유지. `/board/new`·`/repairs/new` GET은 모달이 열린 목록 | 화면 이동 없이 글이 올라감, 오류 때 입력값 남음, 1536×750에서 모달 안 스크롤로 저장 단추에 닿음 |
| Q5 ★ | 정보수리방 분리: `/s/<t>/it`(정보만, 모달은 cat 고정), 게시판 수리 요청은 시설만 + "PC·전자칠판·네트워크 고장은 학교 밖 정보수리방으로" 안내, 알림·돌아가기 링크 정리, 업체 화면 제목도 정보수리방 | 시설 요청이 `/it`·업체에 없고 정보 요청이 교내 탭에 없음. 옛 정보 요청도 `/it`에 나옴 |
