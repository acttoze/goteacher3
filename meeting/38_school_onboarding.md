# 38. 학교 이용 전환·온보딩 방향

- 작성: 2026-11-18 · 리드. 상태: **11/18 사용자 결정 반영, 구현 중.** 학교 확인 단계는 없앴다. 아래 본문과 다르면 "사용자 결정"이 우선한다.
- 사용자 지시(11/18): 학교 이용 버튼 항상 노출, 누르면 1년 무료 안내와 함께 학교로 전환, 다른 학년은 비어 있고 초대 가능, 또는 관리자가 교직원 계정 일괄 생성.
- 검토: `troad-teacher`·`troad-admin`·`troad-productivity`·`troad-uiux`·`gt-security`가 각자 독립 검토(코드 읽기 기준, 실행 검증 아님).

## 결론

**누르면 바로 열리되, 옮겨지는 것은 내 동학년뿐이다.** 다른 학년은 빈 칸으로 초대하고, 이미 있는 동학년은 대표가 합류를 눌러야 옮겨진다. 전 교직원 일괄 등록은 학교 관리자가 쓴다.

지금의 `open_school`을 버튼에 그대로 붙이지 않는다. 가입에 재직 확인이 없어, 외부인이 누르면 다른 동학년의 취합 값이 열리고(`spaces/merge.py:101`) 합쳐진 아이디 회원의 비밀번호까지 바꿀 수 있다(`spaces/school.py:425`). 다섯 검토 모두 같은 지점을 막았다.

## 흐름

1. **상시 버튼**: 왼쪽 메뉴 아래 내 이름 위에 "학교 이용 시작 · 1년 무료". 시작 단계는 상단 바. 상태별로 "우리 학교 공간 들어가기"(이미 열림), "연장"(만료), 계정 잇기(손님)로 바뀐다.
2. **확인 화면 한 장**: 무료 종료일, 카드·자동 결제 없음, 끝난 뒤 달라지는 것, 내가 임시 관리자이고 넘길 수 있음, 우리 학년만 옮겨지고 다른 학년은 그대로. 체크 1개 → "1년 무료로 열기". 보조 선택 "교무부장 선생님께 먼저 물어보기"(제안 문구).
3. **즉시 개통(미확인 학교)**: 학교 공간 생성, 신청자는 임시 관리자, 내 동학년만 합침. 대표가 아니면 대표에게 제안.
4. **학교 시작 보드**(`_school.html`의 "아직 혼자예요" 자리): 1~6학년·교무실·행정실·급식소·기타 10칸, 칸마다 인원과 "이 학년에 보낼 문구 복사". 학년 칸은 나이스 학급 수로 "3/5반". 첫 큰 버튼은 **교무부장께 알리기** 하나, 그다음 학년 초대, 전 교직원 취합 1건.
5. **합류**: 이미 있는 동학년 칸에 "사용 중 · 합류하기". 그 동학년 대표가 누르면 옮겨지고, 그전까지 기존 링크·화면은 그대로.
6. **학교 확인**: 운영자가 학교 대표번호 등으로 확인하면 정식 학교가 된다. 관리자를 교무부장 등에게 넘기는 경로 제공.
7. **일괄 등록(확인된 학교만)**: 이름·소속·반(직책 선택) 붙여넣기 → 신규/기존/동명이인 미리보기 → 개인별 1회용 입장 코드 → A4 절취 쪽지 인쇄. 관리자는 비밀번호를 보지 않는다. 전화·생년월일로 보이는 열은 브라우저에서 제거.

## 미확인 학교의 제한(출시 차단 조건)

- 막는 것: 임시 비밀번호, 일괄 등록, 업체 링크, TV, 합류 전 자료 열람, 학교 사용 수 집계.
- 독점 금지: 미확인 학교가 있어도 새 동학년 생성과 정식 신청을 막지 않고, 확인된 사람이 관리자를 대체한다.
- "우리 학교가 아니에요" 신고, 운영자의 관리자 정지.
- 합류한 손님 회원은 계정을 이을 때까지 학교 화면 차단, 처음 PC를 잃은 사람용 1회 코드.
- 무료 이력은 학교 행에 영구 기록, 계정당 1곳, IP별·일일 개통 한도.
- 학교·학년 초대 링크: 학년은 서버 고정, 만료·사용 상한·폐기, 입장 시도 제한.
