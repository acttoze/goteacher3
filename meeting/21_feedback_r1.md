# 1차 피드백 반영 기록 — 2026-10-26

v1.0 기획서·프로토타입에 대한 1차 피드백과 결정 사항, v1.1 반영 위치.

## 피드백 → 결정

| 영역 | 피드백 | 결정 (v1.1) |
|---|---|---|
| 학교 | 교감 전용·유료 현황판은 관리자 특혜 거부감. 교감은 감시자가 아니고 복무·인사 담당으로 바뀌는 추세 | 현황판을 **전체 교사 공용 '학교' 화면**으로 바꿈. 탭은 학년분장(그룹 현황)·업무분장(부서) |
| 학교 | 복무 현황판은 좋지만 보강은 중요하지 않음(입력하면 이중업무) | 오늘 복무 현황은 유지(공유만), **보강 배정·보결 추천·보강 알림 전부 삭제** |
| 오늘 | 확인 필수·마감 임박을 '오늘'에서 나와 관련된 것으로, 어렵다면 학교 전체로 | '오늘' 오른쪽 칸을 **[나에게 온 것 / 학교 전체]** 토글로. 대상은 그룹·직책·부서로 판정 |
| 그룹 | 연락처·소속·그룹을 '그룹' 개념 하나로. 기본은 학교 공통, 직책 고정 + 수동, 본인 수정, 전체 현황 | 기본 그룹 10개(1~6학년·교무실·행정실·급식소·기타/지원), 직책 목록 + 직접 입력, 본인이 수정(승인 없음) |
| 그룹 | Q1. 부서를 그룹과 따로 둘까 → **따로** | 그룹 = 근무 위치, 부서 = 업무분장 축 |
| 그룹 | Q2. 전담 배치 → **주 학년** | 주 학년 그룹의 '전담' 직책 + 메모(과목) |
| 그룹 | Q3. 교장·보건·사서·상담·특수·돌봄 → **교무실·기타/지원 양쪽** | 공용 직책으로 두 그룹 어디서나 선택 가능 |
| 모으기 | 학교에서는 모바일을 쓰지 않음. 업무는 PC로만 | 받는 화면을 **PC 브라우저**로. 알림은 우상단 🔔 + 웹 알림, **윈도우 PC 에이전트는 차후** |
| 모으기 | hwp 업로드 시 자동으로 열어 취합? 의도 설명 요청 | 의도는 "취합 표만 DB화 → 칸별로 걷기 → hwp로 내보내기"가 맞음. **MVP는 붙여넣기, v1은 hwpx 업로드 후 같은 파일에 채우기, .hwp는 hwpx 저장 안내** |
| 일정 | 칸을 나누지 말고 한 칸에 채널별 색 | 유지·강화(월간 항목에도 유형별 색 적용, 인쇄는 흑백 기호) |
| 일정 | 워크 카드에 제목 + 작성자(그룹) | 주간 `제목 / 송민재 · 4학년`, 월간 `[4학년] 제목` |
| 일정 | 과반 교사가 제목에 내용을 길게 씀 | 한 줄 입력의 **원문을 그대로 제목**으로 저장(날짜·@참석자만 뺌), 달력은 줄바꿈, A3 인쇄 옵션 |

## 추가로 짚은 것
- **교실 화면 송출 문제**: 교사 PC는 수업 중 TV·전자칠판에 미러링되는 일이 많음 → 수업 중 PC 알림 창 금지가 모바일 때보다 더 중요
- **PC 에이전트 리스크**: 학교 PC 설치 권한, 보안 프로그램 충돌, 교육청 화이트리스트
- **유료 모델(2026-10-26 확정)**: '교감 현황판'이 빠져서 다시 짬. 학교가 결제하되 전원이 혜택 → 리마인드 무제한, 원본 hwpx 채워 받기, 그룹·업무분장 연도 보관, SSO, 계산서
