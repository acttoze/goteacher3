# 4차 피드백 검토·반영 기록 — 2026-10-27

v1.3 프로토타입에 대한 4차 피드백, 검토 결과, 반영 위치. 검토 질문은 **2. 다른 사람 일정에 댓글·확인·좋아요·"수고합니다"가 없어도 되나**이다.

---

## 1. 모든 칸에 [＋ 추가], 그 자리에서 바로 입력 (반영)

피드백: 오늘·일정의 모든 셀에 일정 추가 버튼을 둔다. 칸이 꽉 차도 아래쪽에 버튼이 있어야 한다. 입력은 지금 '오늘'처럼 달력에서 바로 하고, 입력창은 기본 2줄로 둔다. 입력창 오른쪽 아래에는 '파일첨부'·'내용입력' 버튼을 작게 단다.

결정:

| 화면 | 칸 | [＋ 추가] 위치 |
|---|---|---|
| 오늘 · 학교 오늘 | 전일 | 카드 목록 맨 끝(카드가 늘면 늘 맨 아래) |
| 오늘 · 학교 오늘 | 1블록 · 2블록 · 3블록 · 방과후 | 왼쪽 **블록 이름 칸 아래**. 카드 영역 밖이라 카드가 꽉 차도 가려지지 않음 |
| 일정 · 주간 | 날짜 × (전일 · 블록 4칸) = 25칸 | 각 칸 맨 아래 줄 |
| 일정 · 월간 | 날짜 칸 | 칸 맨 아래("+N건 별지" 아래) |

- 누르면 **그 자리에 입력창**이 열린다. 기본 **2줄**이고, 오른쪽 아래에 작은 **[파일첨부] [내용입력]**이 있다. 왼쪽 아래에는 "Enter 저장 · Esc 취소"가 흐리게 적혀 있다.
  - **Enter** = 저장, **Shift+Enter** = 줄바꿈, **Esc** = 취소, **바깥을 누르면 저장**(빈칸이면 취소). 한글 조합 중에 누른 Enter는 글자 확정으로만 처리한다.
  - **[내용입력]**을 누르면 같은 창 안에 내용 칸(4줄)이 펼쳐진다. 준비물·참고 사항을 쓰는 곳이고, Ctrl+Enter로 저장한다. 제목 없이 내용만 쓰면 내용 첫 줄이 제목이 된다.
  - **[파일첨부]**로 고른 파일은 창 안에 칩(📎 이름·크기)으로 붙고, ×로 뺄 수 있다. 시연판에는 파일 이름과 크기만 남는다.
- 누른 칸이 날짜와 블록을 정한다. 다만 쓴 문장에 날짜나 블록이 들어 있으면("내일 3블록 …") **문장이 이긴다**. 한 줄 입력과 같은 규칙이다.
- 저장한 카드 제목 옆에 **≡**(내용 있음)과 **📎n**(첨부 n개)이 작게 붙는다. 카드를 열면 '내용'과 '첨부'가 보인다. 내가 고칠 수 있는 카드는 열린 창에서 내용을 고치고 **[저장]**하면 된다. [저장] 버튼은 날짜·시간·내용을 한꺼번에 저장하므로 창 맨 아래로 옮겼다.
- 오늘 화면의 '빈 곳 두 번 누르기'는 아는 사람을 위해 그대로 둔다.
- [＋ 추가]와 입력창은 인쇄에 나오지 않는다.

## 2. 다른 사람 일정에 댓글·확인·좋아요·"수고합니다"가 필요한가 (검토)

**결론: v1에는 넣지 않는다.** 다만 "이 일정 물어볼 게 있는데"와 "봤다는 표시가 필요한 공지"는 따로 해결한다.

넣지 않는 이유:
1. **알림이 늘어난다.** 티로드가 약속한 것은 "수업 중엔 알림 0, 블록 끝에 묶어서"이다. 댓글과 좋아요가 생기면 알릴 일이 사람 수에 비례해 늘어난다. 좋아요 하나에도 작성자는 알림을 받는다.
2. **보이지 않는 의무가 생긴다.** 교무실 메신저에서 이미 겪는 문제다. "수고하십니다"에 답하지 않으면 눈치가 보이고, 좋아요 수를 서로 비교하게 된다. 연령대가 높은 교직원일수록 이 부담을 크게 느낀다. 부장·관리자가 쓴 글에 반응하지 않으면 불편해지는 위계 문제도 따라온다.
3. **댓글이 일정을 바꾸는 통로가 된다.** "장소 체육관으로 바뀐 거죠?" 같은 댓글이 실제 변경을 대신하면 카드의 날짜·장소·블록은 옛날 그대로 남는다. '오늘 바뀐 것'의 신뢰가 깨진다. 변경은 카드 자체를 고쳐서 하고, 알림도 거기서만 나가야 한다.
4. **이미 있는 통로와 겹친다.** 질문은 쪽지(쿨메신저 등)로 이미 오간다. 카드 창에는 [메신저용 문구 복사]가 있어 링크를 붙여 바로 물을 수 있다.

필요한 것만 따로 남긴다:

| 필요 | 지금 v1.4 | 처리 |
|---|---|---|
| 확인했다는 표시 | 공지의 '확인 필수' → 확인함 | **공지에만** 둔다. 일정 카드에는 두지 않는다 |
| 이 일정에 대한 질문 | 카드 창 [메신저용 문구 복사] | 유지. v1에서 반응이 있으면 작성자에게 **쪽지로 묻기**(티로드 안 1:1, 공개 댓글 아님)를 검토한다 |
| 잘못 온 요청 알리기 | (3차 1-2) "제 것이 아니에요" | 모으기에만 둔다 |
| 고마움·격려 | 없음 | 넣지 않는다. 필요하면 학교 문화로 둔다 |

다시 볼 신호: 시범 학교에서 "이 일정 누구한테 물어봐요?"라는 문의가 주 3건 이상이면 '작성자에게 쪽지로 묻기'를 붙인다. 공개 댓글과 좋아요는 그때도 넣지 않는다.

## 3. 확인한 것
- 헤드리스 Chrome(1600px)에서 확인했다. 오늘 블록 4칸·전일, 주간 25칸, 월간 35칸 모두 [＋ 추가] → 2줄 입력 → [내용입력]·[파일첨부] → Enter·바깥 클릭 저장이 동작했다. 저장된 카드는 ≡·📎1 표시를 달았고, 카드 창에 내용·첨부가 보였다. 콘솔 오류는 없었다.
