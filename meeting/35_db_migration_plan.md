# 35. 구버전 → 고티처(새 버전) DB 이관 계획 (초안, 2026-11-09)

근거 데이터는 `34_legacy_db_analysis.md`. 이관 대상은 사용자가 실제로 쓴 **일정·게시판·그룹**과 그 주인인 **회원·학교**다. 출시(12/14, G7 도메인 전환) 때 함께 옮긴다.

## 0. 한 줄 요약

학교마다 학교 공간을 하나씩 만든다. 구 회원은 주인 없는 자리로 미리 넣어 두고, 각자 구글로 처음 들어올 때 **옛 아이디·비밀번호를 한 번 확인해 자기 자리와 잇는다.** 일정은 채널별로 새 범위(학교 전체·그룹·나·복무)에 맞춰 넣고, 게시판은 학교 게시판(Notice)으로 옮긴다. 이관 도구는 다시 돌려도 결과가 같아야 한다. 스테이징에서 리허설한 뒤 출시 주말에 구 사이트를 쓰기 중지하고 최종본을 옮긴다.

## 3. 계정 잇기(가장 중요한 새 기능)

구 회원은 아이디·비밀번호로 로그인했고 gmail은 151명뿐이다. 새 버전은 구글만 받으므로 사람 손을 덜 타는 연결 방법이 필요하다.

1. 이관 때 회원마다 `LegacyAccount`(구 아이디, PBKDF2 해시, 확인 안 된 메일, 이어 줄 Member, 이은 때)를 만든다.
2. 구글로 처음 들어온 사람이 아직 공간이 없으면 "예전 고티처를 쓰셨나요?" 화면을 띄운다. **옛 아이디·비밀번호**를 넣으면 해시(`sha256:12000:salt:hash`, PBKDF2-SHA256)를 검증하고 `Member.user`를 그 구글 계정으로 잇는다.
3. 구글 확인 메일과 구 `mb_email`이 같으면 비밀번호 없이 "이 계정이 맞나요?" 한 번만 묻는다.
4. 비밀번호를 잊은 사람은 학교 관리자가 명부에서 그 자리를 그 사람에게 넘긴다(관리자 화면에 "주인 없는 자리 → 초대 링크로 들어온 사람과 잇기"). 관리자 본인이 잊었으면 운영자가 처리한다.
5. 시도 제한(아이디당·IP당), 잇기 기록. **해시는 잇는 순간, 잇지 않은 것도 2027-03에 지운다.**

현재 학교 입장 흐름은 같은 반·이름의 주인 없는 자리가 있으면 "처음 들어온 PC에서 잇기"로만 보낸다(`spaces/views.py` `_join_school`). 이관 자리에 대해서는 이 안내를 2번 화면으로 바꿔야 한다.

## 5. 검증(끝났다는 기준)

1. 학교별 대조: 범위별 일정 수·게시글 수·회원 자리 수가 보고서의 "옮김 + 버림(까닭별)"과 정확히 맞는다.
2. 격리: 모든 Event·Notice·Member의 공간이 구 `wr_3`/`mb_1` 학교와 같다. 다른 학교 것이 한 건도 없다.
3. 개인 일정: `scope=me` 일정은 작성자 외(관리자 포함)에게 안 보인다. 그룹 일정은 그 소속에게만 보인다.
4. 표본: 학교마다 무작위 20건을 구 화면과 새 화면(1536×750)에서 날짜·제목·범위가 같은지 확인한다.
5. 첨부: 옮긴 파일의 SHA-256이 원본과 같고 내려받기가 된다.
6. 잇기: 구 비밀번호 맞음 → 이어짐, 틀림 → 거부, 시도 제한, 이미 이어진 자리 → 거부, 다른 학교 자리 → 불가.
7. 재실행: 같은 덤프로 두 번 돌려도 건수가 늘지 않는다. 증분 덤프는 새로 생긴 것만 더해진다.
8. 성능: 37곳 전체 적재 10분 안(12/13 작업 시간 확보).

## 6. 전환 날 순서(12/12 금 저녁 ~ 12/14)

1. 구 사이트에 쓰기 중지 공지 → 그누보드 쓰기 막기(읽기 전용 설정, 코드는 맥에서 고쳐 배포 스크립트로)
2. 최종 덤프(M1) → 맥으로
3. 새 운영 DB 백업 → `[시연]` 데이터 삭제 → `import_legacy` 실행 → 보고서 확인
4. 5절 1~3·6 빠르게 재확인
5. Traefik: `goteacher.xyz` → 새 컨테이너, 구 컨테이너 → `old.goteacher.xyz`(읽기 전용). 구글 동의 화면 프로덕션 게시
6. 학교 관리자에게 시작 안내. 첫 주는 매일 잇기 현황(학교별 이은 자리/전체 자리) 확인

되돌리기: 5번 전이면 구 사이트 쓰기만 다시 열면 된다. 5번 뒤 문제가 생기면 라우터를 구 컨테이너로 되돌리고, 그 사이 새 버전에 쓴 것은 따로 받아 둔다.
