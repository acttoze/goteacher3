# 교내·교외 공간 분리 — 2026-10-27

## 왜
교사들이 가장 크게 걱정하는 것: "우리 학교 일정·공지·취합 자료를 외부 업체나 다른 학교가 볼 수 있지 않을까?"
외부인이 들어오는 기능(양식 자료실, 업체 정보, 정보 수리요청)이 학교 메뉴 사이에 섞여 있으면 이 불안이 커진다.
그래서 **화면을 두 공간으로 완전히 나누고, 지금 어느 공간에 있는지 눈으로 바로 알게** 한다.

## 두 공간

| | 교내 | 교외 |
|---|---|---|
| 좌상단 이름 | **학교 이름** (예: 티로드초) | **티로드** |
| 누가 들어오나 | 우리 학교 교직원만 | 다른 학교 교사, 외부 업체, 비로그인 방문자 |
| 메뉴 | 오늘 · 일정 · 모으기 · 게시판(공지 · 시설 수리) · 학교 | 양식 자료실 · 협력업체 · 정보 수리요청 |
| 머리띠 색 | 학교 초록(진한 청록, 흰 글씨) | 남색(흰 글씨) |
| 안내 띠 | 🔒 티로드초 교직원만 보는 공간입니다. 외부 업체·다른 학교는 들어올 수 없어요. | 🌐 학교 밖 공간입니다. 다른 학교 교사와 업체도 봅니다. 우리 학교 일정·공지·모으기는 여기 나오지 않아요. |
| 실제 주소(제안) | `학교코드.troad.kr` | `troad.kr` |

- 공간 전환은 좌상단의 두 칸 스위치 하나뿐. 메뉴끼리 섞지 않는다.
- 교외에서 글을 쓰는 창(후기, 수리 답글)에는 "이 글은 공개됩니다 / 누가 봅니다"를 버튼 바로 위에 적는다.
- 교외의 각 메뉴 제목 옆에 **누가 보는지** 배지를 단다.
  - 양식 자료실: 누구나(로그인 없이)
  - 협력업체: 누구나 보기 · 별점·후기는 인증 교사(티로드 회원)만
  - 정보 수리요청: 우리 학교 교직원 + 계약한 유지보수 업체 1곳만

## 용어: '협력업체'
에듀테크, 졸업앨범·사진, 수학여행·수련활동, 현장체험학습, 전세버스, 찾아가는 교육·체험, 공연·행사, 청소·방역 용역, 인쇄·현수막, 교구·기자재를 한 단어로 묶는다.
학교 행정에서 이미 쓰는 말이라 교사·행정실 모두 낯설지 않다. 메뉴 이름은 **협력업체**.

### 협력업체 화면
- 분류 칩 + 지역(시·도) 필터 + 정렬(별점·후기 수·최근)
- 업체 카드: 이름, 분류, 활동 지역, 평균 별점, 후기 수, "티로드 학교 N곳 이용"
- 별점은 전체 1개 + 항목 4개: **가격 · 응대 · 안전·품질 · 서류 처리**(견적서·사업자등록증·청렴서약서 등 학교 서류를 제때 주는가)
- 후기 작성자는 `인증 교사 · 경기 · 초등`처럼 지역·학교급까지만. **학교 이름·교사 이름은 업체에도 다른 교사에게도 보이지 않음** → 업체가 특정 학교에 항의하거나 보복할 길을 막는다.
- 비회원·업체 계정은 읽기만. 업체는 후기에 답글 1개만 달 수 있다(차기).

### 정보 수리요청을 교외로 옮김
- 시설 수리는 행정실 직원(내부)이 받으므로 교내 게시판에 남긴다.
- 정보 수리는 외부 유지보수 업체가 받으므로 교외로 뺀다. 교사는 "이 글은 업체가 본다"는 것을 쓰는 순간 안다.
- 업체 계정으로 들어오면 **교내 스위치 자체가 잠겨 보이고**(🔒 교직원 전용), 정보 수리요청만 열린다.

## 프로토타입 반영
- 시연 역할에 `누리정보통신 · 유지보수 업체` 추가 → 교내가 잠기는 모습을 보여 준다.
- 주소: 교외는 `#out/forms`, `#out/vendors`, `#out/it`. 옛 주소 `#board/forms`는 교외로 넘김
- 교외에서는 버튼·선택 표시까지 남색으로 바뀌어 화면 어디에도 학교 색이 남지 않음
- 교내 '시설 수리' 옆에 "PC·전자칠판 고장은 교외의 정보 수리요청으로" 안내 카드
- 업체 계정: 교내 칸 흐림+🔒(잠김), 눌러도 안 열림, 🔔 알림 숨김, 교내 주소를 직접 쳐도 정보 수리요청으로 돌아감
- 파일: `app.html`(헤더) · `assets/app.js`(라우터 `setZone`·`outZone`, 수리요청 `repairTab(bb, cat)`, 협력업체 `vendorList`·`vendorView`·`reviewNew`) · `assets/vendors.js` · `assets/style.css` 끝부분
