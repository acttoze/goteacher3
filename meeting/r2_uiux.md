# R2 — 시니어 UI/UX 디자이너

## 1. 쟁점 판정
- **A 확인 모델: 수정 찬성.** '열람=확인'으로 가되, 링크를 열고 2초 이상 보거나 끝까지 스크롤했을 때만 열람으로 친다. 미리보기 봇이 확인율을 부풀리는 걸 막기 위해서다. 재확인은 diff 카드 하나만 보여 준다.
- **B 복무 현황판: 찬성.** 화면은 '오늘' 복무 레인에 "보강 필요 3교시" 빨간 칸을 붙이는 정도로 끝난다. 배정 추천은 v2로 미룬다.
- **C 알림: 찬성.** 시정표를 등록할 때 묶음 알림 시각을 미리 보여 준다. 예: "다음 알림 10:20".
- **D 온보딩: 수정 찬성.** 초대 링크와 QR을 기본으로 쓰고, 업무분장 표를 붙여넣어 구성원을 만든다. 도메인 메일은 선택 사항으로 둔다. 학교 메일을 쓰지 않는 교사가 많다.
- **E 중·고: 찬성.** 단, 데이터 모델에는 '교사 단위 시간표'를 처음부터 넣는다.

## 2. 프로토타입 화면 (우선순위순)
1. **모으기 제출(비로그인 모바일)**: 내 칸만 보인다. 키패드 자동 전환, 30초 안에 제출.
2. **모으기 생성**: 표를 붙여넣으면 머리글이 필드 칩으로 바뀌고, 행 대상을 고르고, 메신저 문구를 복사한다.
3. **모으기 합본**: 실시간 표와 미제출 칩(누르면 독촉 문구 복사), 그리고 hwpx/xlsx 내보내기.
4. **오늘**: 바뀐 것(노랑)을 펼치고, 교시 타임라인과 복무 레인, 할 일함에서 1클릭으로 완료한다.
5. **한 줄 입력**: 입력하면 칩이 실시간으로 나뉜다. 칩을 눌러 고치고 Ctrl+Enter로 저장한다.
6. **공지 v2 diff**: 바뀐 부분은 취소선과 노랑 강조로 보여 준다. '실질 변경' 토글과 "28/32" 확인 현황이 붙는다.
7. **주간/월간 + 인쇄**: 미리보기에서 A4/A3과 흑백 기호를 확인한다.
8. **새 학년 마법사**: 업무분장, 시정표, 특별실을 붙여넣고 초대 QR을 만든다. 3단계로 끝난다.

## 4. 브랜드
- **로고타입/심볼**: 'T'의 가로획을 칠판 청록색 길로 그리고, 세로획 끝에 분필 노랑 점을 하나 찍는다. 점은 "오늘 바뀐 것"을 뜻하고, 앱에서 변경 표시로 쓰는 노랑 점과 같은 기호다. 워드마크는 Pretendard 600 '티로드'로 한다.
- **톤 문구**

  2. "내 칸만 채우면 끝."
  3. "오늘 바뀐 것부터."
