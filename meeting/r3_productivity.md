# R3 운영 가능성 검토: 업무 생산성·협업툴

프로토타입은 교직원 45명이 이미 들어와 있는 학교를 그렸다. 실제 첫날에는 한 사람뿐이고, 그때 살아 있는 화면은 모으기·recv·급식 TV 셋이다.

## 1. 화면별 판정
| 화면 | 판정 | 근거 |
|---|---|---|
| 모으기 | 유지 | 혼자 써도 가치가 나는 유일한 교내 화면이다. |
| recv | 수정 | 명부에서 이름을 고르는데 첫날 명부는 비어 있다. 문자 인증까지 붙으면 30초를 넘긴다 |
| 오늘 | 수정 | 바뀐 것과 나에게 온 것은 다른 사람이 입력해야 채워진다. 첫날은 NEIS 정보만 보인다 |
| 일정 | 수정 | 주간계획 붙여넣기와 월간 인쇄만 남긴다. 블록 끌기와 기간 늘리기는 미룬다 |
| 공지 | 수정 | 쿨메신저와 이중 게시가 된다. 링크와 바뀐 곳 표시만 남긴다 |
| 시설 수리 | 삭제 | 행정실이 들어오지 않으면 요청이 아무 데도 닿지 않는다 |
| 학교 | 수정 | 명부를 확인하는 화면으로 줄인다. 업무분장 탭은 v1로 미룬다 |
| #start | 합침 | 4단계는 2월 전엔 아무도 끝까지 안 한다. 첫 모으기 흐름에 넣는다 |
| 양식 자료실 | 유지 | 운영자가 채우고 검색 유입을 만든다 |
| 협력업체 | 삭제 | 후기는 여러 학교에 교사가 있어야 쌓인다 |
| 정보 수리요청 | 삭제 | 정보부장이 업체를 초대하고 업체가 받아들여야 돌아간다 |
| TV·영양사 | 유지(별도 트랙) | 입력 0으로 돌아가는 유일한 화면이다. 식판 사진 필수와 끌 수 없는 설정은 풀어야 한다 |

## 2. 데이터는 누가 언제 넣는가
- **오늘·일정**: 교무부장이 주간계획 표를 매주 붙여넣어야 화면이 찬다. 붙여넣기가 끊기면 NEIS 정보만 남는다. 고티처도 2026년 작성 1위가 NEIS 봇이다(research/01).
- **나에게 온 것**: 발신자의 모으기와 정확한 명부가 있어야 생긴다.
- **복무**: 나이스와 이중 입력이지만 고티처 제목 14%가 복무라 습관은 있다. 선택 입력으로 둔다.
- **공지 확인율**: 분모가 명부다. 명부가 없으면 숫자를 낼 수 없다.
- **TV**: 사진이 빠진 날 학생 앞 TV에 "사진을 준비하고 있어요"가 종일 뜬다. 없으면 그 화면을 건너뛰어야 한다.
- **콜드 스타트**: 처음 한 사람이 쓰면 오늘에는 급식과 학사일정만, 학교 화면에는 자기 이름 하나만, 게시판에는 아무것도 없다. 시연 데이터가 이를 가린다. 구성원 1명짜리 시드로 검증해야 한다.

## 3. 바이럴 루프 점검
첫 발신자(계원) → 쪽지 링크 → 담임 제출 → 그 담임이 다음 발신자. 고리 세 곳이 끊긴다.
1. **발신자 고리**: 고시트 18건이 보여 주듯 웹으로 걷기만 해서는 구글폼을 못 이긴다. 차별점은 결과가 한글 표로 나오는 것인데, hwpx 채워 받기는 v1로 밀려 있다. 그래서 MVP에서는 "합본 표 복사 → 한글 붙여넣기"가 서식을 깨지 않고 들어가는지가 성패를 가른다.
2. **받는 사람 고리**: 명부가 있어야 이름을 고르는데 명부는 받는 사람이 들어와야 찬다. 반 줄은 NEIS 반 정보로 자동으로 만들고, 받는 사람은 이름 한 칸만 적게 한다. 문자 인증은 '오늘'을 처음 열 때로 미룬다.
3. **다음 발신자 고리**: 완료 화면이 권하는 '오늘'은 첫날 비어 있고, 합본 꼬리말은 결재권자에게만 닿는다. 완료 화면에 "선생님 업무도 한글 표를 붙여넣으면 모을 수 있어요"를 띄운다. 학교 간 확산은 교육청이 학교들에게 걷는 취합에서 노려 볼 만하다(v1 가설).

## 4. 과설계 경고
- **뺄 것**: 교내·교외 스위치(교외 메뉴가 양식 자료실 하나로 줄면 필요 없다), 협력업체, 업체 계정, 수리요청 2종, 그룹별 모으기, 블록 끌기와 크기 조절, 기간 카드 양 끝 끌기, A3 인쇄, TV 순서·노출 시간 설정
- **합칠 것**: 확인 필수 공지는 "필드 0개짜리 모으기"로 본다. 요청 오브젝트를 하나로 만들면 미확인 독촉도 같은 기능으로 해결된다. 학교 화면과 #start는 명부 화면 하나로 합친다. 오늘과 주간은 '이번 주' 전환 하나로 겹침을 정리한다.

## 5. MVP 범위와 성공 지표
- **꼭 넣을 것**: 모으기(직접 입력, 표 붙여넣기, 한 줄형, 여러 줄형 1종), 반 링크 제출(이름 한 칸), 실시간 합본, 미제출 독촉 문구, xlsx 내보내기, 한글 붙여넣기용 표, 제출로 쌓이는 명부, 오늘(NEIS + 나에게 온 것), 공지(바뀐 곳 표시와 링크), 주간계획 붙여넣기, 월간 인쇄, 양식 자료실
- **미룰 것**: hwpx(v1), 문자 인증(v1), 확인 필수 권한, 묶음·웹 알림, 학교 업무분장, 협력업체, 수리요청, 업체 계정. TV는 별도 실험으로 돌린다.
- **성공 지표**
  1. 첫 제출 전환율: 링크를 연 사람 가운데 48시간 안에 제출한 비율 80% 이상, 제출 시간 중앙값 60초 이하
  2. 2번째 발신자: 첫 발신 뒤 30일 안에 다른 교사가 모으기를 만든 학교 40% 이상
  3. 비제출 재방문: 참여 교사 가운데 4주차에 제출 말고 다른 목적으로 '오늘'을 연 비율 30% 이상
