## 결론

- **R1과 같은 제품으로 보인다.** 틀·카드·표·알약·색이 그대로이고, 학교 컨셉 요소가 없고, '티로드' 문구는 화면에 없다. 글자 대비는 스캔한 화면 전부 4.5:1 이상이다.
- **막히는 곳은 겉모습보다 순서와 말이다.** 오늘 화면에서 할 일이 안 보이고, 명부가 첫 화면에 3줄씩만 나오고, 빈 학교 첫 화면이 비어 있는 카드 10장이고, 공지 화면에 '판·v2·실질 변경' 같은 말이 그대로 있다.
- 출시 전 고침 14건, 대부분 템플릿 몇 줄이다. TV·폰·인쇄는 큰 문제가 없다.

## 판단이 필요한 두 가지

두 변경을 CSS로 함께 넣고 19개 화면을 1536·1440폭에서 전후 측정했다.

### (1) `--fs-small` 14px → 15px: 올린다

| 측정 | 결과 |
|---|---|
| 문서 높이 | R1 화면 0~14px 증가(오늘 +7, 동학년 +14, 일정 +10, 모으기 목록·설정·자료실 0). R2 화면 0~32px(학교 +32) |
| 새 줄바꿈 | 1곳: 동학년 화면 초대 안내 `P.small` 한 줄이 두 줄로 |
| 새 잘림·가로 넘침 | 없음. 모으기 목록 제목 잘림은 변경 전에도 있다(아래 13번) |

- 고칠 곳: `web/static/css/gt.css:44`와 `design/assets/gt.css:44`를 15px로. `.pill`(248줄, 글자 14px 고정)도 15px·높이 28px로 함께. 알약에는 '접수'·'아직 안 봄'처럼 꼭 읽어야 할 상태가 들어간다.
- 함께 맞출 고정값: `accounts/settings.html:17·21·25`, `spaces/_join_style.html:14`의 14px을 `var(--fs-small)`로.
- 올리지 않는 예외: `.av`(이니셜), `.ptag`(이름표 13px), 인쇄물(pt 단위, 토큰과 무관). 예외로 `gt.css` 주석에 적어 둔다.
- 얻는 것: 이미 15px인 `.btn.sm`·`.st`·`.notice`와 한 단계로 합쳐져 크기가 실제로 다섯 단계가 된다.
- 비교: `fs15_r1_today.png`·`fs15_r1_list.png`와 `r1_free_today.png`.

### (2) `.seg` 36px → 40px: 올린다. 선택 표시도 같이 고친다

- 실제로 36px인 곳은 **모으기 '새로 모으기'의 방식 선택 하나**다. 오늘·일정·인쇄·업체 화면은 각자 40px로 덮어써 놨다.
- 고칠 곳: `gt.css:189~190`을 `.seg { padding: 2px }`, `.seg button { height: var(--control-h-sm) }`로. 그러면 전체 높이가 44px로 `.btn`과 같아진다(지금 덮어쓴 곳은 48px로 옆 단추보다 크다). 덮어쓰기는 지운다: `today/index.html:72`, `today/schedule.html:8`, `today/print.html:11`, `repairs/vendor/_body.html:13`의 높이.
- **선택 표시가 더 큰 문제다.** 선택된 칸이 옅은 회색 바탕 위 흰색이라 구분이 거의 안 된다(바탕과 약 1.1:1). 업체 화면 상태 4단계에서 특히 걸린다. `gt.css:192`를 `.pick`과 같은 `background: var(--ink); color: #fff`로.
- 비교: `c_new_before.png`, `c_new_seg40.png`, `vendor_home_full.png`.

- **인쇄**: 주간 1쪽, 월중 1쪽+별지, 긴 제목 안 잘림, ◆■▲○ 기호로 흑백 구분, 결재란, 요약·견적서 A4 세로 1쪽. `print_week.pdf`, `print_month.pdf`, `print_summary.pdf`, `print_quote.pdf`, `print_month_p-1.png`
- **급식 입력**: 오늘 칸만 강조, 사진 없으면 빨간 칸 + 파란 단추 + 끌어 놓기 안내. 할 일이 첫 화면에 바로 보인다. `meals_nophoto.png`
- **복무**: 오늘 현황 3열이 한눈에 읽히고, 붙여넣기 뒤 칸이 비워지고, 병가는 '휴가'로 나온다. `school_vp.png`, `attendance_preview.png`
- **업무분장 탭**: 부서 카드 + 담당 + 내 줄 강조. 40명 규모에서 가장 잘 읽힌다. 붙여넣기 미리보기·없는 이름 경고도 좋다. `school_tab_duties_full.png`, `school_duties_preview.png`
- **공지 바뀐 부분 카드**: 취소선 → 굵은 글씨로 무엇이 달라졌는지 바로 보인다. 말만 고치면 된다. `아직 안 봄` 알약도 좋다. `board_detail_unacked.png`, `board_admin.png`
- **수리 요청 양식**: 분류 라디오 + 자기 반 위치가 미리 채워짐 + "급함 — 오늘 수업에 지장". `repairs_new.png`
- **학교 입장, 업체 화면, 후기 쓰기**: 학교 입장은 칩 한 줄, 업체 화면은 위치만 보이는 한 화면, 후기는 공개 범위 경고가 분명하다. `join_new.png`, `join_anon.png`, `vendor_home_full.png`, `partners_review.png`
- **빈 상태 문구**: 게시판·수리·접속 기록·협력업체(등록 0건과 검색 0건을 구분). `board_empty.png`, `partners_none.png`

## 판정 항목 요약

| 항목 | 판정 |
|---|---|

## 확인 못 한 것

- 실제 TV에서 3~5m 거리, 실제 프린터 출력(PDF까지만), 오래된 크롬·웨일(최신 헤드리스 크로미움으로만 봄)
