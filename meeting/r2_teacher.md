# R2 — 4학년 담임(받는 쪽) 의견

## 1. 쟁점별 입장
- **A. 확인 모델: 수정.** '열람=확인'은 찬성합니다. 다만 '확인 필수'는 발신자가 습관처럼 켜게 됩니다. 주당 횟수에 상한을 두고, 재노출은 별도 확인 요청 대신 '오늘 바뀐 것' 노랑 줄 안에서만 해 주세요.
- **B. 보결/복무 현황판: 찬성.** 담임에게는 "3교시 ▶보강 4-1"이 내 시간표 맨 위에 뜨는 것이면 충분합니다. 자동 배정을 v2로 미루는 것도 괜찮습니다.
- **C. 알림: 수정.** 쉬는시간 10분은 화장실 가기도 빠듯합니다. 기본 묶음은 8시·점심·방과후 3회로 하고, 쉬는시간에는 '당일 내 보강'만 보내 주세요.
- **D. 온보딩: 수정.** 초대링크+QR, 업무분장 hwp 붙여넣기로 일괄 생성하는 방식은 찬성합니다. 학교 도메인 메일 인증은 반대합니다. 초등 교사 대부분은 업무용 메일을 쓰지 않습니다.
- **E. 중·고 진입로: 찬성.** 초등 담임과는 상관없는 기능입니다. MVP 범위만 지켜 주세요.

## 2. "현장에선 안 쓴다" 2가지
1. **UI/UX의 단축키 체계(J/K/M/W/D/E)**: 담임은 쉬는시간에 마우스로 한두 번 누르고 끝냅니다. 도움말에 숨겨 두는 정도면 되고, 설계와 홍보에 힘을 쓸 기능은 아닙니다.
2. **교무부장 안의 '나이스 상신했음' 체크와 공문 메타데이터 수기 입력**: 나이스에서 이미 상신했는데 여기서 또 체크하면 이중 업무가 됩니다. 처음 일주일만 누르고 그다음부터는 비어 있을 겁니다. 자동이 아니면 빼 주세요.

## 3. 프로토타입에서 체험하고 싶은 장면
1. **8:35 출근**: 쿨메신저 링크를 누르면 로그인 없이 '오늘'이 뜹니다. 일과 v3에서 바뀐 "5교시 학년체육 강당→체육관"만 노랑으로 보이고, 내 보강(3교시 4-1)과 오늘 마감 1건이 맨 위에 있습니다. 여기까지 30초 안에 끝나는지 보고 싶습니다.
2. **학년 대표 취합**: 체험학습 명단 hwp 표를 붙여넣으면 4개 반 '내 칸만' 링크가 만들어지고 메신저 문구가 복사됩니다. 2반 선생님이 폰으로 제출하고, 3반 미제출 독촉을 1클릭으로 보낸 뒤, hwpx 합본을 내려받기까지 3분 안에 되는지 보고 싶습니다.
3. **쪽지 붙여넣기**: "10/30(목) 5~6교시 4학년 공개수업 협의, 시청각실, 명단 29일까지"를 붙여넣으면 일정과 할일 칩이 나뉘어 나옵니다. 장소 칩 하나만 고쳐 저장한 뒤, 주간 A4 세로로 흑백 인쇄해 교실 게시판에 붙일 수 있는지 보고 싶습니다.
