# R1 제안서 — 시니어 UI/UX 디자이너

## 1. 고티처 UX 진단 Top 7
1. **구조화 필드 없음**: 폼이 그누보드 글쓰기 그대로(제목·시작·종료·색)라 제목 38%에 시간, 14%에 `이름 | 출장(…)`을 손으로 적는다.
2. **필터가 '색'뿐**: 흰·파랑·분홍 3색. 색각이상 교사는 구분이 어렵다.
3. **봐도 안 본다**: 평균 조회 1.73회, 댓글 0.6%. 변경 표시도, '확인' 행동도 없다.
4. **인쇄 깨짐**: Q&A 단골 불만. 방향 선택 다이얼로그 하나가 전부다.
5. **아이콘만 있는 내비**: ◀◀ ◀ ▶ ▶▶, 토요일 토글 `»`에 라벨이 없고, 랜딩 푸터 빈 링크 5개도 스크린리더로 읽히지 않는다.
6. **권한 미로**: 신규 가입자는 글쓰기·메뉴가 막혀 빈 화면을 '고장'으로 여긴다.
7. **목적 혼재**: AI 뉴스가 상단에 있고 모달/사이드바 보기를 사용자가 골라야 하는데, 오늘 할 일로 가는 동선은 없다.

## 2. 정보구조(IA)
최상위 내비는 **오늘 · 일정 · 받기/모으기(취합) · 공지 · 학교(구성원·업무분장)** 다섯 개다. 검색과 설정은 상단 유틸로 뺀다.

```
┌ 티로드  [ 내일 3~4교시 과학실 안전교육 ⏎ ]   🔍  알림3  김교사 ┐
│ 10/26(월) 2주차 · 급식: 잡곡밥… · 결보강 2건                   │
├───────────────┬─────────────────────────┬─────────────────────┤
│ 오늘 시간표     │ 학교 오늘 (교시 축 타임라인)  │ 나에게 온 것           │
│ 1 4-2 과학     │ 1~2 │ 5학년 현장체험(버스)    │ □ 방과후 수요조사 D-1  │
│ 3 ▶보강 4-1   │ 3~4 │ 4학년 안전교육·과학실   │   미제출 12/31         │
│ 5 공강         │ 점심 │ 교직원 협의회(15:00)   │ □ 공지 확인 요청 2     │
│               │ 복무 │ 이OO 출장 · 박OO 조퇴   │ ● 변경됨: 체육대회 우천 │
└───────────────┴─────────────────────────┴─────────────────────┘
```
- 가운데 열은 시계 대신 **교시**를 축으로 쓴다. 복무 레인은 따로 둔다.
- 오른쪽 열은 할 일함이다. 마감, 미제출, 확인 요청, 변경 사항이 여기 모인다.
- 모바일에서는 세 열을 '나 → 학교 → 할 일' 순서의 탭 카드로 접는다.

## 3. 입력 마찰 제거
- **한 줄 입력**: "내일 3~4교시 4학년 과학실 안전교육 @김OO"을 넣으면 날짜 10/27, 교시 3–4, 대상 4학년, 장소 과학실, 참석자 김OO, 유형 '교육'으로 나뉜다. 파싱 결과는 입력창 아래에 칩으로 바로 보여주고, 칩마다 클릭해서 고칠 수 있다.
- 특별실·학년/반·교직원·복무 유형 사전은 학교마다 따로 학습한다.
- **템플릿 재사용**: 지난 행사를 복제하거나, 매주 반복이나 "매월 둘째 수"처럼 주기를 건다.
- **붙여넣기**: hwp나 엑셀 표를 붙여넣으면 행 단위로 일정 초안을 만든다.
- **단축키**: `N` 새 일정, `/` 검색, `T` 오늘, `J/K` 이전·다음 주, `M/W/D` 보기 전환, `E` 편집, `Ctrl+Enter` 저장, `?` 도움말.

## 4. 반응형·인쇄 원칙
- **기준 해상도**: 1920px 교무실 PC가 1순위다. 360px 폰은 '확인·간단 입력'만 맡는다. 1280px에서 세 열이 두 열로, 768px에서 한 열로 바뀐다.
- **오래된 브라우저 대응**: 크롬 80대·구형 웨일까지 지원한다. Grid와 flex gap까지만 쓰고 `:has`는 점진적 향상에만 쓴다. 첫 화면 JS는 150KB 이하.
- **접근성**: WCAG 2.2 AA. 색에는 늘 라벨을 같이 붙이고, 터치 영역 44px 이상, 포커스 링 상시 노출, 200% 확대에서도 레이아웃 유지.
- **인쇄**: 화면을 그대로 찍지 않고 별도 `@page` 레이아웃을 둔다. 월중행사표는 A4 가로/A3 가로, 주간은 A4 세로로 낸다. 흑백으로 출력해도 읽히게 유형은 패턴과 기호(◆행사 ■업무 ○복무)로 구분한다. 공휴일은 음영, 넘치는 칸은 "+3건 별지", 머리말에 학교명·결재란·출력일.

## 5. 비주얼 방향
- **무드**: 잘 정리된 교무수첩. 공문서의 딱딱함은 빼고 표의 정밀함은 살린다. 일러스트나 그라데이션은 쓰지 않고, 사진도 꼭 필요할 때만 넣는다.
- **타이포**: Pretendard(본문 14/22, 표 13/18)를 쓰고, 숫자는 `tabular-nums`로 맞춘다. 제목도 굵기 600까지만 쓴다.
- **밀도**: 기본은 '촘촘'(행 높이 32px)이다. '편안'(40px)으로 바꿀 수 있다.
