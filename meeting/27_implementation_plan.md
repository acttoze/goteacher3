## 0. 한 줄

**2026년 겨울방학 전(12월 14일)에 '동학년판'을 무료로 연다.** 교사가 쉽게 가입하고, 동학년을 바로 만들고, 한글 양식으로 걷고 한글 양식으로 돌려받는 것까지가 범위다. **학교 전체가 돈을 내고 쓰는 '학교판'은 2027년 2월 새 학년 준비 시즌**에 낸다(고티처 방식의 학교 단위 유료 도입).

## 1. 사용자 결정 (2026-10-29)

### 2-1. 무료와 학교 플랜의 경계

| 무료 (개인·동학년) | 학교 플랜 (학교 전체 도입, 연 29~49만 원) |
|---|---|
| 동학년 공간·초대 링크 | 학교 전체 명부·그룹·업무분장(연도 인수인계 포함) |
| 모으기 전부(붙여넣기·직접 입력·자주 쓰는 양식) | 확인 필수 공지·확인 현황, 공지 판 관리 |
| **원본 한글 양식에 채워 받기** | 학교 일정·주간계획·인쇄, 복무 공유 |
| 엑셀·합본 표 복사, 독촉 문구, 마감·기본 리마인드 | 수리 요청 + 정보 업체 계정 |
| 양식 자료실, 협력업체 보기·후기 | 학교 업무 요약(교감·교장 결재용), 급식소 현황판 |
| 간이 '오늘'(나에게 온 것, NEIS 학사·급식) | 리마인드 무제한, 학교 도메인·SSO, 계산서 |

동학년이 무료로 쓰다가 다른 학년·교무부로 번지면, "학교 전체로 쓰자"는 결재가 학교 플랜으로 이어진다. 한글 채워 받기는 퍼뜨리는 힘이라 무료에 둔다.

## 3. R1 동학년판 범위

| # | 기능 | 프로토타입 | 끝났다는 기준 |
|---|---|---|---|

| 2 | **동학년 만들기·초대**: 학년 대표가 만들면 초대 링크·QR이 생긴다. 초대받은 교사는 **가입 없이 이름만** 고르고 들어와도 되고, 나중에 간편 가입으로 이어 붙인다 | (신규) | 4학년 5명이 링크 하나로 다 들어옴 |

| 5 | **교직원 정보만**: 학생 이름·연락처로 보이는 열은 경고하고 인원 수로 바꾸게 안내 | 모으기 만들기 | 감지 규칙 테스트 통과 |

| 8 | 🔔 + 브라우저 웹 알림(묶음 3회: 08:20·12:20·방과후) | 상단 | 수업 중엔 창 알림 없음 |

**R1에서 빼는 것**: 학교 전체 명부·공지·복무·수리·학교 요약·일정 인쇄·급식 TV·협력업체 후기 쓰기(→ R2), 블록 끌기·A3·□ 자리(→ R3).

**모으기 대상 범위(R1)**: 동학년 공간 안에서는 명부로 칸을 만든다. 그 밖의 교사(다른 학년·전담·교무실)에게는 **같은 링크를 쿨메신저로 보내고, 받는 사람이 칸을 고르거나 이름을 적어 내게** 한다. 학교 명부가 없어도 학교 단위 취합이 돌아간다. 이것이 R2 학교판으로 가는 다리다.

| 알림 | 웹 푸시(VAPID) | 이메일·문자 안 씀 |

### 4-1. 데이터 모델 (요지)

```
School(neis_atpt, neis_code, name, plan=free|school)
 └ Space(kind=grade|school, grade, name, invite_token)       ← 동학년이 먼저, 학교판에서 school 공간으로 합침
     ├ Member(name, cls, position, oauth_id?, device_tokens)  ← 이름만 고르고 들어온 사람도 Member
     ├ Collection(title, source=paste|sheet|preset|hwp, due, aud, fields[], footer_on, link_token)
     │   ├ Row(unit, who) ─ Cell(field, value, by, at)
     │   └ SourceFile(원본, 표 위치, 칸 매핑 JSON) → ResultFile(hwp/hwpx)
     └ Event(date, end, slot, target, by, changed_from)        ← 간이 오늘
FormLibrary(운영자 등록)          (R2: Notice, Ack, Attendance, Repair, VendorAccount, MealSettings …)
```

### 4-2. 한글 양식 채워 받기 흐름

1. 업로드: 매직 바이트로 판별한다(`PK`=hwpx, `D0CF11E0`=hwp). hwp는 서버에서 HWPX로 변환하고, 변환 보고에 빠진 요소가 있으면 알린다.
2. 브라우저 rhwp 미리보기에서 표 후보를 점수순으로 강조한다. **교사가 한 번 눌러 확정**한다(자동 1순위 적중률 약 70%).
3. 칸 확인: 자동 라벨을 다듬고, 입력 칸을 켜고 끄고, 행 머리(반·이름)를 배정한다. 합계 행은 뺀다.
4. 링크로 걷는다. 칸 주소(표·행·열) 단위로 병합하고 충돌을 경고한다.
5. 내려받기: 큐가 `fill_cells`(+행 추가)를 돌려 올린 형식 그대로 주고 hwpx도 함께 준다. 쪽수가 늘면 "글자 줄이기"를 띄운다.

- 업로드는 신뢰하지 않는다. 매직 바이트 판별, 크기 제한, lxml 엔티티 해석 끔, zip 폭탄 가드, 작업당 시간·메모리 제한.

- 학생 개인정보는 받지 않는다(감지·경고). 로그에도 남기지 않는다.
