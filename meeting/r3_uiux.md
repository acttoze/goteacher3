## 2. 확정 원칙 위반 (실측)
- **버튼 32px**(`.btn.sm`): 상단 ↺·기획서, 주간계획 표 붙여넣기, A4 선택, 제출·보기, 마감 바꾸기, 독촉 문구 복사, 이름 칩, 전 교직원/1~6학년만/모두 해제, 업체 미리보기, 영양사 '처음 상태로'. [＋ 추가] 31px, 사용자 선택 36px, 숫자 증감 38px.
- **13px 글씨**: 일정 카드 작성자·그룹(오늘 31곳, 주간 62곳), 배지(확인 필수·내 확인 전·v2), 복무 종류, 로고 아래 '교내·교직원만', 세팅 칩 66곳, 양식 '학교/교육청' 배지 42곳. 12px: 시트 A·B·C 머리글, 알림 숫자.
- **14px 보조 글씨 과다**: 학교 80곳, 양식 86곳 → 15px 권장.
- **오래된 크롬·웨일**: `color-mix()` 10곳(Chrome 111 이상)이 깨지면 '바뀐 것' 테두리와 오늘 열 배경이 사라진다. `:has()` 1곳(Chrome 105 이상)이 깨지면 그룹 체크 강조가 사라진다. 대체 색 선언 필요.

## 3. 처음 쓰는 교사가 길을 잃는 지점 Top 5
1. **교내/교외 로고 버튼 2개**: 탭인지 로고인지 모호. 누르면 메뉴가 통째로 바뀌어 "오늘이 사라졌다"고 느낌.
2. **'수리'가 두 군데**에 있다: 게시판 › 시설 수리(교내), 교외 › 정보 수리요청. 교사에겐 같은 "고장 신고".
3. **용어**: 모으기·합본·전일·블록·그룹 선택/그룹별·실질 변경. '그룹 선택'과 '그룹별'은 이름으로 구분 불가.
4. **오늘 오른쪽 목록**: 체크박스, [제출], '보냄' 카드가 섞여 있다. 무엇을 눌러야 끝나는지 모호.
5. **한 줄 입력**: 1440폭에서 안내 문구가 "날짜만 써도 !"에서 잘린다.

## 4. 입력 마찰 (추정)
- **한 줄 입력**: 클릭 또는 N → "내일 2블록 4학년 과학실 안전교육" 약 20자 → Enter. **클릭 1 + 키 21**, 좋다. 칩 고치는 법이 안 보임 → "눌러서 고치기" 한 줄.
- **모으기 만들기**(항목 3개): 새로 모으기 → 항목명 3개 + [＋열] 2 + 형식 3 → 대상(기본값) → 제목 → 만들기 → 관리에서 마감 날짜·시각·[정하기] → 문구 복사 → 쿨메신저. **클릭 약 14, 타이핑 약 40자, 화면 2개**. 줄이기: 표 붙여넣기를 첫 탭으로, 제목은 맨 위로, 만든 직후 '마감+문구 복사'를 한 상자로(→ 클릭 약 9).
- **영양사 사진**: 폰 촬영 → 카톡 '나에게 보내기' → PC 카톡에서 열기 → 복사 → 브라우저에서 영양사 주소 찾기(즐겨찾기가 없으면 학교 › 영양사 입력) → Ctrl+V. **단계 6~7, 매일 반복**. 줄이기: 영양사 주소 바탕화면 바로가기, 폰 QR 업로드 1화면을 PC 전용 원칙의 예외로 검토.

## 5. 급식 TV (55" 1080p, 1px≈0.63mm, 3~5m 기준 글자 약 40~60px 필요)
- **합격**: 오늘의 메뉴(메뉴명 약 64px, 칼로리 96px), 알레르기 타일 이름 44px, 위생 교육, 골고루. 7초 안에 다 읽힌다.
- **불합격**: 알레르기 타일 아래 메뉴 25px, 영양 '기준 13.8 · 164%' 24px, 원산지 28항목 30px(7초에 28개는 무리), 이번 주 급식 메뉴 약 30px·알레르기 번호 약 20px(3m에서 점으로 보인다).
- **조치**: 원산지·이번 주는 12~15초 또는 분할. 영양 9종 → 3종(탄수화물·지방은 기준 막대도 없음). 사진이 없으면 학생 TV에 "영양 선생님이 올려 주세요"가 뜸 → 교직원용 문구 숨기고 메뉴로 대체.

## 6. 구현 계획 전에 꼭 고칠 것 (우선순위)
1. **버튼과 글씨 하한 일괄 적용**: `.btn.sm` 폐지(최소 40px), 13px → 15px, 배지 14px. 
2. **1536×750 기준 '오늘' 접힘선 확보**: 교내 띠는 첫 방문만, 정보줄·바뀐 것 압축, 내 시간표 위치 고정.
3. **교내/교외 전환 방식 재설계**: 로고 2개 대신 '학교 밖 자료실 ↗' 링크 하나. 수리 요청은 교내 한 곳에서 받아 업체로 넘김.
4. **오른쪽 목록의 행동 통일**: 항목당 [제출]/[확인] 하나, 체크박스 제거, 보낸 것과 낼 것 구역 분리.
5. **TV 원거리 기준 확정**: 최소 40px, 정보량별 노출 시간, 학생 화면에 교직원 문구 금지. 함께 `color-mix`/`:has` 대체 색.
