# 고티처 코드 기능 인벤토리 요약 (코드 기준)

## 캘린더 필드
wr_1/2 시작·종료일(날짜만, 시간 없음) · wr_3 학교 · wr_4 채널 레인(0·1 공통, 2 복무 "이름|복무", 3 개인, 4 내 소속, 5+ 커스텀) · wr_5 완료(일정당 1개 플래그) · wr_6 공지 · wr_7 작성자 소속 · wr_8 열람 제한 mb_id 목록 · wr_9 색 인덱스(14=NEIS) · wr_10 NEIS 숨김

- 읽음 로그: (글,회원) 1회, 열람 제한 글은 작성자에게 푸시
- NEIS 학사일정 주1회 봇 등록, 급식 매일 캐시
- 없음: 반복 일정, 시간 단위 일정, 시간 기반 리마인더, 외부 캘린더 연동, 사람별 완료

## 기타 기능 성숙도
GoSheet(Tabulator+JSON, 30분 셀잠금, 실시간X) 중하 · 연락망(그룹 CRUD, 엑셀 매칭, 임시 PW 12345678) 중상 · 양식 자료실(SEO용 게시판) · AI 뉴스(콘텐츠) · gomemo 하 · 채널 19건 · school_dashboard.php 고아 페이지 · 웹 FCM(댓글/쪽지/열람 이벤트만) · 구매는 게시판 수작업

## 가입
그누보드 가입 → 시도·학교 검색 → 학교 로그인 리다이렉트 → 4자리 PIN 동료에게 받아 입력(최대 마찰). 코드 변경 시 전원 재로그인. PIN 평문.

## 팀 자체 진단
학교당 활성 2.9명 → "캘린더가 아니라 일기장", 이탈 43.5%, 알림 부재, 모바일 열악. 우선과제: 알림·반복일정·알림톡·PWA·학교 단위 도입·PIN 해싱. 회의록.md는 AI 시뮬레이션(실 인터뷰 아님).
